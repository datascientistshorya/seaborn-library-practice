📊 Seaborn Library Practice

A hands-on repository dedicated to learning and practicing data visualization using Seaborn in Python.
This repo documents my journey in mastering visual storytelling, exploratory data analysis (EDA), and statistical plotting.

🚀 Overview

Seaborn is a powerful Python visualization library built on top of Matplotlib that makes it easier to create informative and attractive statistical graphics.

This repository contains notebooks and exercises where I experiment with different Seaborn plots, styling options, and real-world datasets to strengthen my data visualization skills.

📁 Repository Contents

Distribution plots (histplot, kdeplot)

Categorical plots (boxplot, violinplot, barplot)

Relationship plots (scatterplot, pairplot, heatmap)

Styling and themes

Exploratory Data Analysis (EDA) examples

Real dataset visualizations
